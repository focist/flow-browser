# Arc Browser Features Analysis

This document contains the complete list of 41 features that Arc browser has but are missing from Flow Browser's COMPLETED or UPCOMING documentation.

## Missing Features from Flow Browser's Roadmap

### **Core Interface & Navigation**
1. **Favorites System** - Universal tabs that transcend spaces and appear at the top of sidebar with keyboard shortcuts (Cmd+1, Cmd+2, etc.)
2. **Command Bar with Universal Search** - Spotlight-style command interface that searches websites, URLs, browser history, and performs browser actions
3. **Tab Auto-Archive System** - Automatic archiving of unused tabs after predetermined time intervals with user-configurable timing
4. **Library Central Hub** - Unified location for downloads, archived tabs, media captures, easels, and cross-space tab management
5. **Today Tabs Auto-Management** - Automatic tab lifecycle management where regular tabs automatically close/archive unless pinned

### **Visual Customization & Productivity**
6. **Boosts (Website Customization)** - Advanced website customization using CSS, HTML, and JavaScript with shareable boosts gallery
7. **Split View (Up to 4 Tabs)** - Native browser split-screen supporting up to 4 tabs simultaneously in one window
8. **Picture-in-Picture Auto-Activation** - Automatic PiP mode when switching tabs with playing video content
9. **Desktop Capture Integration** - Built-in screenshot/capture tools with Shift+Command+drag functionality
10. **Website Live Screenshots** - Camera icon in URL bar for capturing website sections with intelligent area suggestions

### **Advanced Workspace Management**
11. **Cross-Space Favorites** - Favorites that appear in all spaces regardless of current space context
12. **Per-Profile Archive Settings** - Individual archive timing configuration for each browser profile
13. **Space-Transcendent Tab Management** - Tab hierarchy system with favorites > pinned > today tabs
14. **Profile-Scoped Data Management** - Complete separation of logins, cookies, browsing history, and settings per profile
15. **Multi-Space Tab Overview** - Library view showing tabs across all spaces simultaneously

### **Creative & Collaboration Tools**
16. **Easels (Digital Whiteboards)** - Built-in creative workspace for drawing, writing, collecting images, and brainstorming
17. **Easel Screenshot Integration** - Direct capture-to-easel functionality with drag-to-select screen areas
18. **Easel Sharing & Collaboration** - Share easels with others and export to various formats
19. **Easel Video URL Integration** - Paste video URLs to create playable video embeds in easels
20. **Alignment Guides in Easels** - Visual guides for precise object placement within easel workspace

### **AI & Intelligent Features**
21. **Ask on Page** - AI assistant that answers questions about current webpage content
22. **5-Second Previews** - AI-generated webpage summaries on link hover
23. **Instant Links** - AI browsing that finds results without showing search engines
24. **Live Folders** - AI-powered folders that automatically organize and add new content based on learned preferences
25. **AI-Powered Website Content Learning** - System that learns user preferences and automatically surfaces relevant content

### **Tab Management & Organization**
26. **Little Arc (Mini Browser)** - Lightweight temporary browser window for quick link access
27. **Drag-to-Split Tab Creation** - Drag tabs to create split views with visual drop indicators
28. **Tab Renaming** - Ability to rename tabs with double-click or right-click functionality
29. **Archived Tabs Search** - Searchable archive of all previously closed tabs with cross-space functionality
30. **Tab Auto-Disappearing Logic** - Intelligent system where unpinned tabs automatically disappear after set time

### **Advanced Browser Features**
31. **Built-in uBlock Origin Integration** - Native ad blocking with uBlock Origin engine integration
32. **Chrome Extension Support with Privacy Focus** - Full Chrome extension compatibility with Google components stripped
33. **Multiple Tab Split Ordering** - Drag tabs to specific positions (left/right) in split view configurations
34. **Cross-Platform Universal Binary** - Native support across macOS, Windows, iOS, and Android
35. **Space Theme Customization** - Visual theming system for different spaces with custom icons and colors

### **Workflow & Productivity**
36. **Tab Lifecycle Automation** - Automatic tab management based on usage patterns and time-based rules
37. **Media Management Hub** - Centralized management for all images, videos, screenshots captured during browsing
38. **Download Management Integration** - Downloads integrated into main Library interface with progress tracking
39. **Cross-Device Space Syncing** - Spaces, pinned tabs, and active tabs sync across all devices
40. **Keyboard Shortcut System for Favorites** - Dedicated keyboard shortcuts (Cmd+1-12) for instant favorite access
41. **Google Meet Integration** - "Share This Tab Instead" functionality and meeting join shortcuts
